# Third-party notices

The frontend uses these libraries:

- Three.js — MIT. https://github.com/mrdoob/three.js
- fflate — MIT. https://github.com/101arrowz/fflate
- texture2ddecoder-wasm — MIT. https://github.com/fatal10110/texture2ddecoder-wasm

Build and test dependencies include Vite (MIT) and Playwright (Apache-2.0).

The build copies the complete runtime library license texts to `dist/licenses/`. The decoder's license is also copied beside its WebAssembly files. Dependency packages retain their original notices in `node_modules/`.
