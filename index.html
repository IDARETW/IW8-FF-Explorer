A closer look at your extraction

1. Open a fastfile

Select a Replay .ff file from your device or the server browser. ACTS extracts all supported assets and GLB model previews automatically, then opens the output. Progress and previous results are in Extractions. You can also open an existing extracted folder or ZIP. Include manifest.json and assets.jsonl to attach asset names and export details.

2. Preview an asset

DDS textures include mip, face, array layer, and volume slice controls where available. Common BC formats decode on the CPU, including BC7. Float texture previews clamp values to 0–1.

Use GLB, glTF, or OBJ for models. ACTS Replay can create a .geometry.glb sidecar with --geometry. This shows base surface geometry. Packed .shared.bin files alone do not contain enough information for a model preview.

Replay models use their matching material and DDS color textures. The server loads companion materials and referenced shared textures automatically. Use Textures to compare with plain geometry, or Material set when several model variants share the same mesh. Missing dependencies are shown in the preview. For portable ZIPs, include the model, image files, asset journals and material records.

3. Move around

Drag to rotate. Use the wheel or pinch to zoom. Right-drag or use two fingers to pan. Use Frame to center the model, Wireframe to inspect edges, or Z-up for raw game-oriented models.

Local by design

Ordinary imported asset files remain in memory on your device. Fastfile uploads and extracted output are saved in the server cache. The authenticated PC service is required for automatic extraction and host file browsing. Files referenced by a model must be imported with it. External URLs in models are blocked.

ZIP imports allow 512 MB expanded, 256 MB per file, and 20,000 files. For larger collections, import a folder and select smaller preview files. Text previews show the first 1 MB; downloads retain the complete original.
